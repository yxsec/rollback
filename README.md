# RollGain

This repository accompanies RollGain and its paper, *Exploiting Ethereum
Rollback Semantics: Profit-Driven Attack Synthesis and Off-Chain
Misinterpretation Testing*. The current public release contains the benchmark
datasets: 43 profitable-contract samples and 14 honeypot and trap-behavior
samples, together
with their Solidity sources, manifests, and audit metadata. The analysis
implementation, attack-synthesis and PoC-generation components, and off-chain
testing tools are not included in this release and will be considered
separately after security and misuse review.
